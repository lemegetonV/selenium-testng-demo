## Plan amendments to apply during this scaffold

Before generating code, please apply these corrections to PLAN.md (in 
AI-docs/PLAN.md) and reflect them in the code you generate. Log each 
amendment under a new "Plan Amendments" subsection in CLAUDE.md's 
Progress Log entry for this prompt.

1. **Drop firstName/lastName from the User POJO.** The login flow uses 
   email and password only. Billing names come from TestDataFactory. 
   User POJO has two fields: email, password.

2. **Redefine Product as a runtime capture record.** It's not loaded 
   from JSON. It's populated at runtime from the search result tile 
   (or PDP, depending on what Prompt 04 reveals) so CartPage can assert 
   on name and price later. Implement it as a Java record:
   `public record Product(String name, String price) {}`
   Place it in com.demowebshop.models alongside the POJOs.

3. **DriverFactory owns ChromeOptions configuration.** It reads the 
   following keys from ConfigReader and applies them:
   - headless (boolean) → adds --headless=new
   - Standard noise-suppression flags always applied: 
     --disable-notifications, --disable-gpu (headless only), 
     --remote-allow-origins=*, --no-sandbox (headless only), 
     --window-size=1920,1080
   Add a one-line javadoc on the options builder method explaining 
   what each flag does (grouped, not per-flag).

4. **Hard assertions only.** Use TestNG's Assert.assertEquals / 
   assertTrue / assertNotNull at test layer. Do not introduce SoftAssert 
   anywhere. Framework-level validations (e.g. WaitUtils timeouts) 
   throw FrameworkException, not AssertionError.

5. **testng.xml includes listener registration and suite parameters.** 
   Generate testng.xml at project root with:
   - suite name, parallel="none", thread-count="1"
   - listener: com.demowebshop.listeners.ExtentReportListener
   - suite-level parameters: browser (chrome), baseUrl 
     (https://demowebshop.tricentis.com)
   - one <test> block referencing the tests package
   BaseTest reads these suite parameters via @Parameters 
   annotation with defaults falling back to ConfigReader.

6. **@Jacksonized rule, explicit.** Every POJO loaded from JSON gets 
   @Data @Builder @Jacksonized. POJOs only generated by 
   TestDataFactory (never deserialized) get @Data @Builder only. 
   Apply this rule consistently — don't sprinkle @Jacksonized at 
   random.

7. **WebDriverManager: setup() only, no manual system property.** 
   Call WebDriverManager.chromedriver().setup() in DriverFactory and 
   stop there. Do NOT call System.setProperty("webdriver.chrome.driver", 
   …) afterward — that can override Selenium Manager with a stale 
   binary. The earlier PLAN.md note suggesting otherwise is wrong; 
   correct it in place.

8. **logs/ directory handling.** Configure log4j2.xml's RollingFile 
   appender with createOnDemand="true" so the logs/ directory is 
   created at first run without requiring a committed .gitkeep. 
   Confirm logs/ is in .gitignore.

### Core utilities (src/main/java/com/demowebshop/)

Implement each with real, working code. Not stubs.

- **config/ConfigReader.java** — loads config.properties once via static 
  block; getString, getInt, getBoolean with System.getProperty precedence 
  over file values; throws FrameworkException if a required key is 
  missing and no default supplied.

- **driver/DriverFactory.java** — ThreadLocal<WebDriver>; 
  initDriver(String browser), getDriver(), quitDriver(); 
  WebDriverManager.chromedriver().setup() before instantiation; 
  ChromeOptions per amendment 3; applies pageLoadTimeout from config.

- **core/FrameworkException.java** — extends RuntimeException, two 
  constructors (message, message+cause).

- **core/BasePage.java** — abstract; constructor takes WebDriver; 
  instantiates and exposes protected final ElementActions actions and 
  protected final WaitUtils wait fields.

- **core/ElementActions.java** — the heart of the framework. Implement 
  ALL of these methods with the patterns described in PLAN.md and 
  CLAUDE.md:
  - click(By, String description) — 3-tier fallback: native → scroll 
    + native → JS executor. Log DEBUG on native/scroll success, WARN 
    on JS fallback success. Wrap the chain in single-retry on 
    StaleElementReferenceException. Only catch 
    ElementClickInterceptedException and ElementNotInteractableException 
    to trigger fallback — other exceptions fail fast.
  - type(By, String text, String description) — wait for visible, 
    clear, send keys. Password-masking: if description lowercased 
    contains "password", "cvv", "card number", "credit card", log 
    "****" instead of the actual value.
  - selectByVisibleText(By, String, String description)
  - selectByValue(By, String, String description)
  - getText(By, String description)
  - isDisplayed(By) — returns boolean, swallows NoSuchElementException 
    only, no screenshot on miss
  - isPresent(By) — DOM presence, no visibility requirement
  - waitForText(By, String expectedText) — assertion-style wait; 
    throws FrameworkException on timeout
  - scrollIntoView(By) — JS scroll via JavascriptExecutor
  - hover(By, String description) — Actions API
  
  Every method logs intent at INFO before acting, logs failures at 
  ERROR with context, captures a screenshot on failure via 
  ScreenshotUtils, and rethrows wrapped in FrameworkException.

- **utils/WaitUtils.java** — wraps WebDriverWait; forVisible(By), 
  forClickable(By), forInvisible(By), forText(By, String), 
  forUrlContains(String); reads explicitWaitSeconds from config.

- **utils/ScreenshotUtils.java** — captureBase64() returns String for 
  Extent; captureToFile(String name) saves to reports/screenshots/ 
  with safe filename (sanitize description → alphanumeric + 
  underscore); wipeScreenshotsFolder() for BaseTest @BeforeSuite 
  (uses commons-io FileUtils.cleanDirectory).

- **utils/TestDataReader.java** — generic <T> T load(String 
  filename, Class<T> type) using Jackson ObjectMapper; resolves from 
  src/test/resources/testdata/ via classpath.

- **utils/TestDataFactory.java** — Datafaker-backed. Methods: 
  generateBillingAddress(), generateCreditCard(), 
  generatePhoneNumber(). Seedable via dataFakerSeed config key 
  (single global seed, sequential execution only). Return POJOs 
  populated with realistic US-format values (the demo site expects 
  US addresses).
